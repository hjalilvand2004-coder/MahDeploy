## ✨ معرفی

**MahDeploy (استقراربان)** فرآیند استقرار اپلیکیشن‌های **FastAPI (بک‌اند) + React (فرانت‌اند)** را روی **ویندوز سرور** استاندارد و خودکار می‌کند:

- 🔍 **پیش‌بررسی هوشمند قبل از استقرار** — بررسی سلامت سرور، آزاد بودن پورت، صحت DNS دامنه و اعتبارسنجی مسیر گواهی SSL؛ تا همه‌چیز سبز نشود، نصب شروع نمی‌شود
- 🧙 **ویزارد ۵ مرحله‌ای استقرار** — جمع‌آوری دامنه/پورت/مسیر/گواهی ← نمایش پلن ← تأیید ← اجرای اسکریپت‌های PowerShell با **ترمینال زنده** ← راستی‌آزمایی نهایی
- 🌐 **Nginx Reverse Proxy خودکار** — ساخت کانفیگ HTTPS (پورت ۴۴۳)، پروکسی `/api` به uvicorn و سرو استاتیک React + تنظیم فایروال
- ⚙️ **بک‌اند به‌صورت سرویس ویندوز** — ثبت خودکار با **WinSW** (شروع خودکار با بوت سرور + ری‌استارت در صورت کرش)
- 📊 **داشبورد سلامت سرور** — CPU / RAM / دیسک به‌صورت زنده، نقشه پورت‌های اشغال‌شده و جریان رخدادها
- 🗂 **مدیریت سیستم‌های مستقرشده** — مشاهده وضعیت، شروع/توقف/ری‌استارت/حذف، مشاهده اسکریپت‌ها و لاگ‌ها
- 🔐 **احراز هویت مدیر** — رمز پیش‌فرض `admin1234` (قابل تغییر از داخل پنل)، نشست امضاشده HMAC
- 🎨 **رابط فارسی RTL** با طراحی شیشه‌ای (Glassmorphism)، پس‌زمینه Aurora و انیمیشن‌های نرم

## 📦 نسخه پرتابل (پیشنهادی)

نیازی به نصب **هیچ** پیش‌نیازی نیست — Node.js و تمام ران‌تایم‌ها داخل بسته هستند:

1. فایل `MahDeploy-Portable-Windows-x64-v1.1.0.zip` را از بخش [Releases](../../releases) دانلود کنید
2. در مسیر دلخواه (پیشنهاد: `C:\MahDeploy`) باز کنید
3. روی `Start-MahDeploy.bat` دوبار کلیک کنید → پنل روی `http://localhost:3000` باز می‌شود
4. ورود: `admin` / `admin1234` — و بلافاصله رمز را عوض کنید!

| نیاز سیستم | حداقل |
|---|---|
| سیستم‌عامل | Windows 10/11 یا Windows Server 2016+ (x64) |
| رم | ۵۱۲ مگابایت آزاد |
| دیسک | ۳۰۰ مگابایت |
| پیش‌نیاز نرم‌افزاری | **هیچ!** (نه پایتون، نه Node، نه دیتابیس) |

## 🛠 ساخت سرویس ویندوز (شروع خودکار)

در پوشه پکیج، PowerShell با دسترسی Administrator:

```powershell
powershell -ExecutionPolicy Bypass -File .\service-install.ps1     # نصب + شروع سرویس
powershell -ExecutionPolicy Bypass -File .\service-uninstall.ps1   # حذف سرویس
```

## 🏗 ساخت پکیج پرتابل از سورس

```powershell
powershell -ExecutionPolicy Bypass -File .\build-portable.ps1
```

خروجی: `dist\MahDeploy-Portable-Windows-x64-v1.1.0.zip` (نیازمند Node.js 20+ و اینترنت)

ساخت از سورس (لینوکس/macOS یا WSL):

```bash
bun install          # یا npm install
bun run db:push      # ایجاد دیتابیس
bun run dev          # توسعه
bun run build        # بیلد production (خروجی standalone)
```

## 📁 ساختار پکیج پرتابل

```
MahDeploy\
 ├─ Start-MahDeploy.bat      اجرای پنل (دوبار کلیک) — پورت اختیاری: Start-MahDeploy.bat 8080
 ├─ Stop-MahDeploy.bat       توقف پنل
 ├─ service-install.ps1      ثبت سرویس ویندوز (WinSW)
 ├─ service.xml              تنظیمات سرویس
 ├─ runtime\node.exe         ران‌تایم Node.js 22 (داخل‌بسته)
 ├─ app\                     برنامه پنل (Next.js standalone + Prisma + SQLite)
 ├─ data\mahdeploy.db        دیتابیس پنل — پشتیبان‌گیری فقط همین فایل!
 └─ logs\                    لاگ‌های اجرا
```

        ▼

## 🔒 نکات امنیتی

- رمز پیش‌فرض `admin1234` را **بلافاصله** تغییر دهید
- پنل را فقط از طریق شبکه مورد اعتماد در دسترس قرار دهید؛ برای انتشار عمومی از Nginx + SSL جلوی پنل استفاده کنید
- اسکریپت‌های استقرار پیش از اجرا نمایش داده می‌شوند و اجرای هر مرحله نیازمند تأیید شماست
- اسکریپت‌های PowerShell به‌طور موقت در `%TEMP%\deployguard` نوشته و پس از اجرا حذف می‌شوند
